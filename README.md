# Ecommerce-website

A full-stack e-commerce web application that allows users to browse products, add items to their shopping cart, and manage their purchases. The platform supports two types of accounts: Users and Sellers, each with their own functionalities.

--Features

->User

User authentication and login.
Browse available product listings.
Add products to the shopping cart.
Manage cart items.

->Seller

Dedicated seller login.
Add new product listings.
Edit existing product details.
Delete product listings.
Upload product images using image URLs.

->Tech Stack
Backend:
Node.js
Express.js

Database:
MongoDB Atlas
Mongoose


->Future Improvements

Direct image uploads instead of relying only on image URLs.
Payment gateway integration.
Order management and order tracking.
Product search and filtering.

Note: This project was built to practice full-stack web development, backend API development, database integration, authentication, and CRUD operations.
